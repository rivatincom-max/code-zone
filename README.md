# CODE: FROM ZERO — PWA

Готовое PWA-приложение учебника программирования. Проект можно опубликовать через GitHub Pages.

## Публикация через GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи **все файлы из этой папки в корень репозитория**: `index.html`, `manifest.webmanifest`, `sw.js`, иконки.
3. Открой репозиторий → **Settings** → **Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Подожди завершения публикации. GitHub покажет адрес вида `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Важно: не открывай сайт через `file://` для проверки PWA. Service Worker работает на HTTPS или localhost. GitHub Pages предоставляет HTTPS автоматически.

## Установка на iPhone

1. Открой опубликованный адрес в Safari.
2. Нажми «Поделиться».
3. Выбери «На экран Домой».
4. Подтверди добавление.

После первой загрузки приложение сможет открывать учебник без интернета благодаря Service Worker. Для первого кэширования открой сайт при подключённом интернете.

## Обновление

После изменения файлов загрузи их в GitHub. При следующем открытии Service Worker обновит кэш. Если изменения не появились сразу, закрой приложение полностью и открой снова.

## Структура

- `index.html` — интерфейс и содержание курса.
- `manifest.webmanifest` — настройки PWA.
- `sw.js` — кэширование для офлайн-работы.
- `icon.svg`, `icon-192.png`, `icon-512.png` — иконки приложения.

Прогресс уроков хранится локально в браузере этого устройства. Он не синхронизируется автоматически между разными устройствами.
