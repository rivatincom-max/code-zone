Перед началом: что такое код?

Программа — это набор точных инструкций для компьютера. Ты описываешь, что должно произойти, а компьютер выполняет инструкции.

Например: «получи два числа, сложи их и покажи ответ». Программирование — это умение разбить большую задачу на маленькие понятные шаги.

Как начать практиковаться

Если у тебя есть компьютер с Windows

  1. Установи Python с официального сайта python.org. Во время установки на Windows отметь Add Python to PATH.
  2. Установи редактор Visual Studio Code.
  3. В VS Code создай папку learning-code и файл lesson1.py.
  4. Напиши print("Привет, мир!"), сохрани файл и запусти его через кнопку запуска Python или терминал командой python lesson1.py.
  5. Для JavaScript сначала можно использовать консоль браузера: открой инструменты разработчика и вкладку Console. Позже установим Node.js с nodejs.org.

Если сейчас только телефон

Читай курс и пробуй небольшие примеры в браузерных песочницах:

  • Programiz Python Online Compiler — запуск Python.
  • Programiz JavaScript Online Compiler — запуск JavaScript.
  • CodePen — эксперименты с HTML, CSS и JavaScript.
На телефоне удобно изучать основы, но собирать полноценные Windows-приложения и EXE лучше на компьютере. Сам учебник адаптирован под экран телефона.

Мини-словарь программиста

Переменная

Именованное место, где программа хранит значение. Например, age = 20.

Функция

Повторно используемый блок кода, который выполняет задачу. Например, функция приветствия.

Условие

Проверка, от которой зависит дальнейшее действие программы: если условие верно, сделай одно, иначе другое.

Цикл

Повторение команды или блока команд несколько раз.

Библиотека

Готовый набор кода, который можно подключить, чтобы не писать всё самостоятельно.

Фреймворк

Набор инструментов и правил, который задаёт основу приложения.

Интерфейс (UI)

То, что видит пользователь: окна, кнопки, меню, поля и экраны.

Бэкенд

Внутренняя часть приложения: обработка данных, правила, сервер и доступ к базе данных.

Баг

Ошибка или нежелательное поведение программы.

Компиляция и сборка

Процесс подготовки проекта к запуску или распространению. Конкретный способ зависит от технологии.
